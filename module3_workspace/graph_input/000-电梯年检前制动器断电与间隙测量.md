# 电梯年检前制动器断电与间隙测量
Wiki page id: 019fd112-0000-7000-8000-000000000022
Page type: PROCEDURE
Summary: 执行制动器间隙调整前，应先将电梯运行至顶层并切断主电源，再使用塞尺测量闸瓦与制动轮间隙，确认其在 0.3mm 至 0.5mm 标准范围内。

1. 将电梯运行至顶层并切断主电源。
2. 使用塞尺测量制动器闸瓦与制动轮之间的间隙，标准值为 0.3mm 至 0.5mm。
