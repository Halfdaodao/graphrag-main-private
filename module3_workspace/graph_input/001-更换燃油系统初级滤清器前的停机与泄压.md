# 更换燃油系统初级滤清器前的停机与泄压
Wiki page id: 019fcfff-0000-7000-8000-000000000021
Page type: PROCEDURE
Summary: 执行滤清器更换前，应先停机并等待发动机冷却，再缓慢松开加注口盖释放压力。

1. 停止发动机并等待冷却。
2. 缓慢松开冷却系统加注口盖，释放系统压力。
